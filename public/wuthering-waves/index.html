About Wuthering Waves

Wuthering Waves (often abbreviated as Wuwa) is an open-world action RPG developed by Kuro Games. Set in a post-apocalyptic world, players control Rover and explore Sol-3, fighting enemies called Tacet Discords while uncovering the mystery of the Lament.

The game uses a gacha system similar to Genshin Impact, with character event banners, weapon banners, and a standard banner. Pity carries over between banners, and there's a 50/50 mechanic for featured 5-star characters.

This is an unofficial fan resource. Wuthering Waves is developed by Kuro Games. Astral Wish Lab is not affiliated with or endorsed by Kuro Games.
